# Controls
* Forward = Left analog stick up
* Strafe Left = Left analog stick left
* Strafe Right = Left analog stick right
* backpedal = Left analog stick down
* Run = Left trigger
* Fire = Right trigger
* Use = A button
* Turn Left = C stick
